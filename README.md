# All Seasons Tree Surgery Ltd

Next.js website for **All Seasons Tree Surgery Ltd**, an Orpington-based tree surgery, hedge care and landscaping business.

## Current direction

- Next.js App Router + React + TypeScript
- Responsive, mobile-first brochure/lead-generation site
- Seasonal presentation with spring, summer, autumn and winter content
- Autumn is selected automatically for September–November
- Real project photography is the primary visual language
- Service-specific SEO routes
- LocalBusiness structured data, sitemap and robots metadata
- Mobile Call / WhatsApp / Quote actions

## Development

```bash
npm install
npm run dev
```

Type-check with:

```bash
npm run typecheck
```

Production build:

```bash
npm run build
```

## Environment

Copy `.env.example` to `.env.local` and set the final public site URL:

```
NEXT_PUBLIC_SITE_URL=https://example.com
```
